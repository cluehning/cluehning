## 🔬 Current Projects
I’ve committed to creating **one project per month**, each sitting at the intersection of mathematics, computation, and biology.

### 🧪 [Atom Simulation](https://github.com/cluehning/juli_atoms)
Real‑time OpenGL visualization of hydrogenic atomic orbitals, probability densities, and quantum flow fields.

### 🧬 [EPIGO](https://github.com/cluehning/september_nn_EPIGO)
EPIGO treats epigenetic tracks as structured objects rather than unrelated lists.  
This version adds a neural representation‑learning layer to:
- measure genomic signal geometry  
- compress it  
- reconstruct it  
- evaluate information preservation

### 📊 [EPIGO_Matlab](https://github.com/cluehning/april_EPIGO_Matlab)
A Matlab‑based exploration of numerical methods, modeling, and applied mathematical experimentation.
